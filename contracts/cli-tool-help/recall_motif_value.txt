chitta recall_motif_value - Return top-k CDAWG motif states reachable from (tool, entity) ranked by Q-value: which action sequences have the highest expected success rate from this context?

Parameters:
  --entity (required)

  --k
      Max states to return (default 5)
  --tool (required)


Example:
  chitta recall_motif_value --tool "..." --entity "..."
