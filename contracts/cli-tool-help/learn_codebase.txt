chitta learn_codebase - Learn codebase by extracting symbols. path can be a local directory or a remote git URL (https://github.com/..., git@github.com:...). Remote repos are shallow-cloned into a temp dir, indexed, then deleted.

Parameters:
  --branch
      Branch, tag, or commit to clone (remote only)
  --embed
      Embed symbols synchronously (default false; use embed_symbols separately)
  --exclude

  --force

  --incremental

  --max_files

  --path (required)
      Local path or remote git URL
  --project
      Project name (defaults to repo/dir name)

Example:
  chitta learn_codebase --path "..."
