chitta learn_codebase - Learn codebase by extracting all symbols

Parameters:
  --path (required)
      Directory path to analyze
  --project
      Project name (auto-detected if empty)
  --max_files [default: 500]
      Max files to process
  --exclude
      Comma-separated directories to exclude
  --force [default: false]
      Reprocess all files even if unchanged (repopulates callsites)

Example:
  chitta learn_codebase --path "..."
