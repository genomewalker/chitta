chitta update_task - Update task status (Active=0, Blocked=1, Completed=2, Failed=3, Abandoned=4), optionally attach an intervention ID or add a tag

Parameters:
  --add_intervention_id
      Attach intervention to task
  --add_tag
      Add a tag to the task
  --status (required)
      0=Active 1=Blocked 2=Completed 3=Failed 4=Abandoned
  --task_id (required)
      Task ID

Example:
  chitta update_task --task_id "..." --status "..."
