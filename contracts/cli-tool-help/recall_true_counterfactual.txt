chitta recall_true_counterfactual - Return decision points where (tool, entity) was explicitly considered and rejected. Uses the DecisionTape (Phase 10), not CDAWG sibling inference. Requires prior log_event_ex or log_decision calls.

Parameters:
  --entity (required)

  --k
      Max results (default 5)
  --outcome
      0=success 1=fail 2=error (default 0)
  --tool (required)


Example:
  chitta recall_true_counterfactual --tool "..." --entity "..."
