chitta provenance_check - Deterministic anti-reprocessing check: has this file/task already been processed? Exact keyed lookup of a prior [done] record by content-hash and/or input path — bypasses fuzzy recall. Returns found + the record.

Parameters:
  --input
      Input path (fallback handle)
  --sha
      Content hash of the input (tried first — content identity)

Example:
  chitta provenance_check
