chitta memory_outcome - Record an observed outcome for a memory into its Beta utility posterior (success raises alpha, failure raises beta)

Parameters:
  --id (required)
      Node ID the outcome is about
  --success (required)
      Did acting on this memory work?
  --weight
      Observation weight, capped at 5.0 (default 1.0)

Example:
  chitta memory_outcome --id "..." --success "..."
