chitta recall_temporal - Search memories within a time window (defaults to last 7 days)

Parameters:
  --end
      End date
  --include_global
      Include global memories
  --limit
      Max results (default 20)
  --query
      Optional semantic search query
  --realm
      Filter by realm
  --start
      Start date (ISO8601 or YYYY-MM-DD)

Example:
  chitta recall_temporal
