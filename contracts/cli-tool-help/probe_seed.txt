chitta probe_seed - Store an exemplar text as a centroid for a behavioral class (sycophantic/hedging/shallow/direct). Bootstrap the probe with representative examples.

Parameters:
  --class (required)
      Behavioral class: sycophantic | hedging | shallow | direct
  --note
      Optional annotation
  --text (required)
      Exemplar text for this class

Example:
  chitta probe_seed --class "..." --text "..."
