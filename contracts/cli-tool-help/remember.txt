chitta remember - Store text in memory with optional tags and realm

Parameters:
  --confidence
      Initial confidence 0-1 (default: 0.8)
  --content (required)
      Text to remember
  --realm
      Primary realm (default: brahman)
  --shared_realms
      Additional realms
  --tags
      Optional tags
  --type
      Node type (wisdom, insight, signal, episode)
  --visibility
      0=Private, 1=Shared, 2=Global (default: 0)

Example:
  chitta remember --content "..."
