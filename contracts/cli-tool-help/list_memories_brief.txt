chitta list_memories_brief - List memories with full content, realm, and tags (JSON-per-line). Used by enrichers.

Parameters:
  --limit [default: 200]
      Max memories to return (default 200)
  --offset [default: 0]
      Pagination offset
  --realm [default: ]
      Filter by realm
  --kind [default: ]
      Filter by kind

Example:
  chitta list_memories_brief
