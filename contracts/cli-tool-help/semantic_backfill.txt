chitta semantic_backfill - Dense-kNN SemanticNeighbor edge backfill: link each memory to its top-k realm-scoped HNSW neighbors (cosine>=min_cos) with bidirectional similarity edges. First real memory<->memory knowledge relation. Dry-run by default (counts, no writes).

Parameters:
  --apply [default: false]
      Create the edges (default false = dry-run count only)
  --k [default: 6]
      Neighbors per memory (default 6)
  --min_cos [default: 0.6]
      Minimum cosine to link (default 0.6)

Example:
  chitta semantic_backfill
