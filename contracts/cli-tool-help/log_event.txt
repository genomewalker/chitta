chitta log_event - Log a structured action event to the CEC tape and CDAWG

Parameters:
  --tool (required)
      Tool name (e.g. Edit, Bash)
  --entity (required)
      Entity acted on (file, URL, command)
  --outcome [default: 0]
      0=success 1=fail 2=error 3=partial
  --session_id [default: 0]
      Session ID (optional)
  --ts_ms [default: 0]
      Timestamp ms (0=now)

Example:
  chitta log_event --tool "..." --entity "..."
