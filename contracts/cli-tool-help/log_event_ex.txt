chitta log_event_ex - Log a CEC event with regret-shaping telemetry (token_cost, latency_ms, retry_count). Updates Q-values with utility = outcome_reward - 0.001*token_cost - 0.00001*latency_ms - 0.1*retry_count.

Parameters:
  --entity (required)

  --latency_ms
      Wall-clock ms (0=unknown)
  --outcome
      0=success 1=fail 2=error 3=partial
  --retry_count
      Retries before this outcome
  --session_id

  --token_cost
      Tokens consumed (0=unknown)
  --tool (required)

  --ts_ms


Example:
  chitta log_event_ex --tool "..." --entity "..."
