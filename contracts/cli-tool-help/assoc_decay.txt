chitta assoc_decay - Gate B: decay + floor-prune one assoc EdgeType (wire numbering 0-5, default 3=CoRetrieved). Every edge weight is multiplied by factor; edges below prune_below are removed. apply=false is a dry run (counts only). One-shot saturation migration: factor=1.0, prune_below=0.2. Snapshot before apply.

Parameters:
  --apply

  --edge_type

  --factor

  --prune_below


Example:
  chitta assoc_decay
