chitta-field — Rust memory store

Memory lives in chitta-field, an embedded Rust store linked into the daemon. Claude Code and Codex sessions share the daemon over RPC; one daemon owns each store through an instance lock.

Each memory is encoded as a sparse code: exactly 64 of 16,384 feature dimensions activate. Recall is driven by overlap between patterns, not keyword matching. Memories with overlapping active features become retrieval candidates.

Snapshots and uncovered write-ahead log records recover the store. Ordinary WAL syncs are batched on a 200 ms timer; explicit durable operations force persistence. Warm sidecar startup measured about 9.5 s on the current live store, with about 20 s for the first start after deployment.

Write-Ahead Log

Operations are logged in CRC-validated segments. Snapshot families plus uncovered WAL recover the store. Multiple agent sessions share one owning daemon; ordinary syncs are batched.

Cortical Posting Index

Each active feature maintains an inverted list of memories it belongs to. Recall intersects the k posting lists for the query's top-k features. Sub-millisecond, no HNSW4 graph traversal.

Organic Decay

Memories move through tiers based on access frequency and recency. Frequently accessed memories are promoted; inactive memories are demoted over time.

chitta-research — autonomous research

chitta-research is an autonomous research system built on chitta-field. Seven specialized agents coordinate to explore a research agenda, build a structured belief graph, and store durable findings across sessions.

Each research session accumulates into a belief graph: ResearchProgram → Question → Hypothesis → ExperimentPlan → Run → Observation → Claim → Method. Findings persist in chittad — the same daemon that powers chitta.

Brahman, the coordinating agent, enforces a research constitution: self-improvement depth cap, hard novelty stop, and a hypothesis backlog gate that prevents runaway recursion.

Belief Graph

Research accumulates as a typed graph: Programs link to Questions, Questions to Hypotheses, Hypotheses to ExperimentPlans and Runs. Claims and Methods are first-class nodes. The graph is stored across sessions.

Brahman Constitution

The coordinating agent enforces hard limits: self-improvement depth cap prevents recursive self-modification spirals; novelty stop halts when marginal gain drops below threshold; hypothesis backlog gate prevents queue saturation.

Install & Run

make install drops cresearch into your PATH. Point it at an agenda YAML and it runs. Findings surface in chitta memory automatically — the same chitta recall that powers your daily sessions.
