Skills Reference

31 slash-command skills

Skills are slash commands that expand into specialized prompts. They are namespaced by plugin, so each is invoked as /chitta:<name>. They guide Claude through structured workflows — from soul initialization to autonomous development rituals.

Status as of 2026-09-19 · Names follow the repository's skill directories; maintenance suffixes were retained during the rename.

Memory Operations Session Continuity Reasoning Development Learning & Curiosity Maintenance System Benchmarking
